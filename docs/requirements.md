Функциональные требования

FR-01: Вход в систему по логину и паролю.
FR-02: Управление меню: добавление, редактирование, удаление позиций (название, категория, цена, себестоимость).
FR-03: Управление клиентами: добавление, редактирование (ФИО, телефон, email).
FR-04: Создание заказа: выбор клиента и позиций меню, указание количества.
FR-05: Фиксация цены на момент продажи (price_at_sale), чтобы изменения прайса не искажали прошлую выручку.
FR-06: Смена статуса заказа: «Новый» → «Готов» → «Выдан».
FR-07: Просмотр списка заказов с фильтром по статусу и дате.
FR-08: Расчёт выручки за месяц по выданным заказам.
FR-09: Расчёт прибыли с учётом себестоимости (cost_price).
FR-10: Роли пользователей: Администратор и Бариста (разные права доступа).
FR-11: Блокировка учётных записей пользователей.

Нефункциональные требования

NFR-01: Время отклика на основные операции — не более 2 секунд.
NFR-02: База данных — SQLite (файл coffee.db, без отдельного сервера БД).
NFR-03: Бэкенд на Python 3.10+ и Flask 2.3+.
NFR-04: Пароли хранятся в хешированном виде (bcrypt).
NFR-05: Защита от SQL-инъекций через SQLAlchemy ORM.
NFR-06: Адаптивный интерфейс (mobile-first).
NFR-07: Простое развёртывание: один процесс + файл БД, без внешних сервисов.
NFR-08: Резервное копирование — копирование файла базы данных.
NFR-09: Интерфейс доступен согласно WCAG 2.1 AA.

User Stories
US-01: Как бариста, я хочу быстро создавать заказы, чтобы обслуживать клиентов без задержек.
US-02: Как админ, я хочу добавлять позиции в меню с ценой и себестоимостью, чтобы вести актуальный прайс.
US-04: Как бариста, я хочу видеть цену позиции при оформлении заказа, чтобы не ошибиться.
US-05: Как бариста, я хочу менять статус заказа («Новый» → «Готов» → «Выдан»), чтобы отражать ход работы.
US-07: Как админ, я хочу видеть выручку за месяц, чтобы отслеживать доход.
US-11: Как сотрудник, я хочу входить по логину и паролю, чтобы получить доступ к своим функциям.
US-14: Как админ, я хочу обновлять себестоимость позиций, чтобы расчёт прибыли был точным.
US-15: Как бариста, я хочу, чтобы цена в старом заказе не менялась после обновления меню, чтобы отчёты оставались верными.
US-16: Как бариста, я хочу видеть только свои рабочие экраны, чтобы не отвлекаться на лишние настройки.
